# Temple Images Setup Guide

## New Temple Images to Download

Download these images from the internet and place them in `darshan-backend/assets/images/`:

### 1. Kedarnath.jpg
**File name**: `Kedarnath.jpg`
- Search for: "Kedarnath Temple Uttarakhand"
- Good sources: Wikipedia, Unsplash, Pexels
- Size: ~500x400px or larger
- Save to: `darshan-backend/assets/images/Kedarnath.jpg`

### 2. Somnath.jpg
**File name**: `Somnath.jpg`
- Search for: "Somnath Temple Gujarat"
- Good sources: Wikipedia, Pixabay, Unsplash
- Size: ~500x400px or larger
- Save to: `darshan-backend/assets/images/Somnath.jpg`

### 3. KamakhyaDevi.jpg
**File name**: `KamakhyaDevi.jpg`
- Search for: "Kamakhya Temple Assam"

### 4. KashiVishwanath.jpg

### 5. Meenakshi.jpg
**File name**: `Meenakshi.jpg`

- Good sources: Wikipedia, Commons, Unsplash
- Size: ~500x400px or larger

## Steps to Add Images:
1. Download the 5 images from internet sources
2. Place them in: `darshan-backend/assets/images/`
3. Run the seed script: `node seed.js`
4. Restart frontend and backend servers

## Recommended Download Sources:
- **Wikipedia Commons**: commons.wikimedia.org (free, high quality)
- **Unsplash**: unsplash.com (free, high resolution)
- **Pexels**: pexels.com (free stock photos)
- **Pixabay**: pixabay.com (free images)
